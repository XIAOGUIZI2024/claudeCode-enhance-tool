# Claude Code 功能增强安装包

## 包含功能
1. **StatusLine 状态栏** — 显示当前目录、模型、上下文使用进度条
2. **智能通知** — 你离开电脑时自动弹出 Windows 通知提醒，你在看的时候不会打扰

## 使用方式

1. 打开 cmd，运行 `claude` 进入 Claude Code
2. 输入以下命令：

```
请执行当前目录下的 install.ps1 脚本来安装 Claude Code 增强功能
```

3. 等待 Claude 自动完成安装
4. 重启 Claude Code 即可生效

## 系统要求
- Windows 10 或更高版本
- 建议安装 Python（用于状态栏功能）
- 建议安装 Git for Windows（提供 bash 环境）
